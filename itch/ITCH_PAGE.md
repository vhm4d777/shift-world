## Description (paste into the description editor)

**SHIFT WORLDS** is a pixel-art puzzle-platformer about living in two worlds at once.

You fell into the seam between two parallel dimensions: the bright **Light World** and the neon **Dark World**.
Press **SHIFT** to cross between them instantly, even in mid-air. Each world has its own platforms, its own hazards and its own monsters,
and the only way forward is to use both.

**Every world-shift changes the rules:**
- **Wardens** patrol the Dark. In the Light they freeze into crystal, so you can stand on them.
- **Wisps** hunt you through the Dark and lose interest in the Light.
- **Sentinels** fire only in the Dark. Shift to Light to make their bolts vanish.
- **Machines** run in the Light. In the Dark, time stands still.
- Bridges, walls and spikes that exist on only one side.

**Features**
- 10 handcrafted levels, from a gentle tutorial to the final challenge, *The Rift*
- A hidden **Memory Shard** in every level. Can you find all 10?
- Adaptive soundtrack: the Light and Dark themes play together and crossfade every time you shift
- Checkpoints, levers & gates, crumbling bridges, moving platforms and lifts
- Best times, a death counter and an optional speedrun timer
- Keyboard, mouse and gamepad support, plus auto-save

Made for **GitHub Game Off 2026**, theme **SHIFT**. Built with Godot 4.

### Installation
**Windows:** download the ZIP, right-click → *Extract All*, then run `ShiftWorlds.exe`. No installer is needed.
If SmartScreen says "Windows protected your PC", click *More info → Run anyway* (the game isn't code-signed).
You can also install and update it through the **itch.io app**.

**Linux:** extract the ZIP and run `ShiftWorlds.x86_64`.

### System requirements
- Windows 10/11 64-bit (or 64-bit Linux)
- Graphics card with OpenGL 3.3, or DirectX 11 on Windows
- 2 GB RAM, 150 MB free disk space
