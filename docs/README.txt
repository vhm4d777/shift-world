SHIFT WORLDS  v1.0.0
=====================
A pixel-art puzzle-platformer about shifting between two parallel worlds.
Made for GitHub Game Off 2026 (theme: SHIFT).

HOW TO PLAY
-----------
Windows : double-click ShiftWorlds.exe
          (If "Windows protected your PC" appears: More info > Run anyway.
           The game is not code-signed, which is normal for indie games.)
Linux   : run ./ShiftWorlds.x86_64   (chmod +x ShiftWorlds.x86_64 if needed)
macOS   : right-click "SHIFT WORLDS.app" > Open (unsigned build)

No installation is needed. The game runs from this folder and you can move it anywhere.
To uninstall, delete this folder (and, if you like, the save folder below).

CONTROLS
--------
Move ............ A / D  or  Arrow keys      (gamepad: left stick / d-pad)
Jump ............ Space  (hold to jump higher)   (gamepad: A)
SHIFT WORLDS .... Shift  (also X or K)        (gamepad: X or bumpers)
Restart level ... R                           (gamepad: Y)
Pause ........... Esc or P                    (gamepad: Start)
Fullscreen ...... F11

TIPS
----
- Faded, dotted outlines show what exists in the OTHER world.
- You can shift in mid-air.
- You can't shift if the other world has something solid where you stand.
- Every level hides one Memory Shard. Find all 10!

SAVE DATA
---------
Progress saves automatically:
Windows: %APPDATA%\ShiftWorlds\     Linux: ~/.local/share/ShiftWorlds/
macOS:   ~/Library/Application Support/ShiftWorlds/

SYSTEM REQUIREMENTS
-------------------
Windows 10/11 64-bit (or 64-bit Linux / macOS 10.13+)
OpenGL 3.3 or DirectX 11 graphics, 2 GB RAM, 150 MB disk
